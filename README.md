# 英文文献阅读助手

两个互补的 Codex skill：先理解一篇论文，再读懂其中难懂的段落。默认使用中文讲解。

## 包含哪些技能

| 技能 | 适合的场景 | 主要输出 |
| --- | --- | --- |
| `paper-insight` | 速读指定论文，或深入理解其中的方法 | 研究问题、动机、已有方法不足、核心方法与创新 |
| `explain-paper-passage` | 阅读英文文字或截图中的难懂片段 | 先忠实讲解原意，再单独补充概念与推理难点 |

`paper-insight` 的默认讲解面向学过概率论、数理统计和机器学习、科研经验较少的本科生。可以在请求中说明自己的基础和希望的深度。

这是两个独立技能的文件合集，不是独立应用，也不是插件安装包。

## 在 Codex 中安装

解压压缩包，保留两个技能各自的完整文件夹。打开 Codex，把解压后的真实路径提供给它，例如：

> 请将这个文件夹里的 paper-insight 和 explain-paper-passage 两个技能安装到我的个人技能目录。如果存在同名技能，请先说明差异，不要直接覆盖。文件夹路径是：〔替换为解压后的 skills 文件夹路径〕。

根据安装时的提示完成操作，再在能够发现这两个技能的聊天中使用。

## 使用示例

### 先理解整篇论文

提供论文 PDF 或可访问的论文链接，并输入：

> 请用 $paper-insight 帮我读懂这篇论文，重点讲清研究动机、核心方法和创新。我学过概率论和数理统计，但科研经验不多。

### 再读懂具体段落

粘贴英文文字或上传清晰截图，并输入：

> 请用 $explain-paper-passage 讲解这段内容，先用自然中文忠实说明原意，再补充难懂的概念和推理。

截图尽量包含完整句子。涉及上一段的指代、符号或定义时，一起提供相关上下文。

## 阅读时的注意点

讲解用于辅助理解，关键定义、公式、假设和研究结论仍应与原文核对。缺少上下文或图片不清晰时，应保留不确定性。辅助例子和补充解释不等于论文作者的原话或研究结果。
